P19 / 2025.08-2026.05 / Custom Implant Design Automation

맞춤형 보형물 설계 자동화 도구

Rhino와 Grasshopper로 만든 코 보형물 설계 자동화 도구를 138개 버전까지 발전시켰습니다. CT 분할 파이프라인이 만든 STL과 주문 정보를 받아 기준 정렬, 보형물 설계, 확인서와 도면, 몰드와 STL 파트까지 설계자가 노드를 보지 않고 7단계 UI로 끝냅니다. 내부 성과보고서(2026.03) 기준 평균 설계시간은 373분에서 150분으로 약 60% 줄었고, 디자인팀 4명이 매달 약 150건을 이 도구로 설계합니다.

UI 흐름 보기 소프트 변형 노드 버전 흐름 보기 노드 규모 보기
내 역할 설계와 구현 단독: Grasshopper 형상 로직, raised-cosine 소프트 변형 노드, Human UI 7단계 작업자 화면, 문서와 STL, 몰드 자동 생성. 기획서, 일정관리, 진행 보고도 직접 맡았습니다.
사용 기술 Rhino, Grasshopper, Human UI, parametric geometry, STL, mold automation
결과 내부 성과보고서(2026.03) 기준 평균 설계시간 373분에서 150분(약 60% 단축), 숙련도 격차 288분에서 60분, 긴급 리드타임 5영업일에서 2영업일. 디자인팀 4명이 매달 약 150건을 이 도구로 설계합니다. 138개 버전, 최종 정의 15,337개 오브젝트.

Design Automation

설계자가 노드를 몰라도 순서대로 따라갈 수 있는 설계 도구가 필요했습니다.

노드 캔버스에서는 설계자가 지금 어느 단계인지 알기 어려웠고, 입력 순서를 틀리거나 노드를 잘못 건드려 결과가 틀어지는 일도 막기 어려웠습니다. 그래서 핵심 알고리즘을 모듈로 떼어 내고, v3.0부터 Human UI로 캔버스를 가린 마법사형 UI를 만들었습니다. 매개변수 입력, 최적화, 정렬, 보형물 설계, 출력 파일 생성이 이 UI 한 곳에서 끝납니다.

Pipeline position

CT 분할 결과로 설계를 시작하고, 몰드는 MoldTrace에서 다시 확인합니다.

주문 정보와 세부 요청사항을 넣고, 제가 운영하는 CT 분할 파이프라인에서 나온 뼈와 피부 STL을 파트 데이터로 불러와 설계를 시작합니다. 이 도구가 만든 몰드는 MoldTrace에서 제조 컨펌 대화와 함께 다시 확인합니다.

Operator UI

왼쪽에서 오른쪽으로 진행되는 7단계 작업 UI

설계자 옆에서 작업 화면부터 보고, 기능 목록 대신 실제 작업 순서대로 7단계를 나눴습니다. 노드 기반 자동화를 먼저 만든 뒤, 사용성을 올리려고 제가 추가로 만든 UI 계층입니다.

Soft deformation node

Grasshopper에 없는 소프트 변형은 네이티브 노드로 직접 만들었습니다.

라인을 기준으로 주변 메쉬를 부드럽게 끌어오는 소프트 변형은 Grasshopper 기본 노드로 만들 수 없었습니다. 그래서 raised-cosine falloff로 라인 메쉬를 변형하는 네이티브 노드를 직접 구현했습니다. raised-cosine falloff는 기준에서 멀어질수록 이동량이 코사인 곡선을 따라 0까지 줄어들어, 변형된 부분과 그대로인 부분의 경계가 꺾이지 않고 이어집니다.

Initial schedule 2025.08 - 2025.10

이 일정표 기준의 개발은 노드 기반 자동화까지가 중심이었습니다. 이후 작업자가 쓰기 쉽게 만들기 위해, 본래 계획 밖에서 UI/UX 계층을 추가로 올렸습니다.

  1. 2025.08 초 높이차 자동계산 및 시각화

    초기 기준값을 자동으로 읽고 화면에서 확인할 수 있게 만든 첫 계획 항목입니다.

  2. 2025.08 초 배면(Supratip) 부위 미세 수정

    노드 조작으로 세부 부위를 수정할 수 있게 만든 설계 보정 구간입니다.

  3. 2025.08 중 정면 형태/볼륨 조절 통합

    형태와 볼륨 조절 로직을 하나의 설계 흐름으로 묶었습니다.

  4. 2025.09 해부학적 지점 자동 표시

    설계자가 확인해야 하는 기준점을 화면에 자동으로 표시하는 항목입니다.

  5. 2025.09 코 RP 모형 자동 생성

    점막을 포함한 코 모형 출력 파일을 설계 결과에서 자동으로 만들었습니다.

  6. 2025.09 보형물 정보 자동 각인

    결과물 관리와 제작 식별을 위해 자동 각인 흐름을 포함했습니다.

  7. 2025.09 기술 도면 자동 생성

    설계 결과를 문서와 도면 산출까지 이어지게 만들었습니다.

  8. 2025.09 사전확인서(PDF) 생성

    설계 검토 문서를 PDF로 자동 생성하는 항목입니다.

  9. 2025.10 3D 프린팅용 몰드 생성

    제조 단계로 넘기기 위한 몰드 생성과 각인까지 포함했습니다.

  10. 2025.10 주입구/배출구 자동 계산

    출력 이후 제작 공정까지 고려한 자동 계산 항목입니다.
