Design Automation

노드 자동화가 아니라, 작업자가 따라갈 수 있는 설계 시스템이 필요했습니다.

Grasshopper 캔버스 환경은 로직의 고도화와 무관하게 설계자가 제어 단계를 직관적으로 파악하기 어려워 오작동률이 높았습니다. 이를 개선하기 위해 핵심 알고리즘을 독립 모듈화하고, v3.0부터는 비주얼 노드 캔버스를 격리하는 Human UI를 구축했습니다. 매개변수 입력, 최적화, 정렬, 임플란트 설계 및 출력 파일 생성까지 마법사형 UI로 일원화한 설계 자동화 도구의 아키텍처적 기반이 되었습니다.

Planning / pre-UI

처음 개발 범위는 UI가 없는 Grasshopper 노드 기반 설계였습니다.

초기에는 간트차트를 만들어 일정과 보고를 관리했고, 실제 개발 범위도 Grasshopper 노드를 조작해 설계하는 방식이었습니다. 문서상 PM 표기는 함께 있었지만, 기획서 작성, 일정관리, 진행 보고, 구현 흐름 정리는 대부분 제가 직접 처리했습니다.

Initial schedule 2025.08 - 2025.10

이 일정표 기준의 개발은 노드 기반 자동화까지가 중심이었습니다. 이후 작업자가 쓰기 쉽게 만들기 위해, 본래 계획 밖에서 UI/UX 계층을 추가로 올렸습니다.

  1. 2025.08 초 높이차 자동계산 및 시각화

    초기 기준값을 자동으로 읽고 화면에서 확인할 수 있게 만든 첫 계획 항목입니다.

  2. 2025.08 초 배면(Supratip) 부위 미세 수정

    노드 조작으로 세부 부위를 수정할 수 있게 만든 설계 보정 구간입니다.

  3. 2025.08 중 정면 형태/볼륨 조절 통합

    형태와 볼륨 조절 로직을 하나의 설계 흐름으로 묶었습니다.

  4. 2025.09 해부학적 지점 자동 표시

    설계자가 확인해야 하는 기준점을 자동으로 표시하도록 계획했습니다.

  5. 2025.09 코RP 자동화

    반복되는 보형물 설계 계산을 자동화 범위로 끌어올렸습니다.

  6. 2025.09 보형물 정보 자동 각인

    결과물 관리와 제작 식별을 위해 자동 각인 흐름을 포함했습니다.

  7. 2025.09 기술 도면 자동 생성

    설계 결과를 문서와 도면 산출까지 이어지게 만들었습니다.

  8. 2025.09 사전확인서(PDF) 생성

    설계 검토 문서를 자동으로 생성하는 흐름을 계획했습니다.

  9. 2025.10 3D 프린팅용 몰드 생성

    제조 단계로 넘기기 위한 몰드 생성과 각인까지 포함했습니다.

  10. 2025.10 주입구/배출구 자동 계산

    출력 이후 제작 공정까지 고려한 자동 계산 항목입니다.

Grasshopper v5.0

15,337개 오브젝트 규모의 최종 통합 정의

최종 통합 5.0 버전은 전체 구조를 한 화면에서 보려면 이렇게 축소해서 볼 수밖에 없었습니다. 설정, UI, 문서, 보형물 설계, STL 파트 제작이 한 정의 안에 묶여 있고, 아래 모듈맵은 그 구조를 공개 범위에 맞춰 설명하기 위해 다시 표시한 이미지입니다.

Module History

기능별로 쪼개고, 검증하고, 다시 v5.0으로 통합했습니다.

처음부터 하나의 거대한 정의를 만든 것이 아니라, 경계라인 추출, Wrap 생성, 도면 추출, 사전확인서, 형태/볼륨 조절 같은 기능을 따로 만들고 검증한 뒤 최종 통합 버전으로 묶었습니다.

01 분리

경계라인, Wrap, 도면, 사전확인서, 형태/볼륨 조절 같은 기능을 별도 모듈로 쪼갰습니다

02 검증

각 모듈을 실제 케이스에서 확인하고 필요한 파라미터와 예외를 계속 보강했습니다

03 통합

통합 3.x, 4.x를 거쳐 신규 몰드 자동 생성까지 포함한 v5.0으로 묶었습니다

04 운영

실무자가 노드가 아니라 UI 순서대로 작업하도록 저장/불러오기와 결과 산출 흐름을 붙였습니다

Public-safe note

실제 캡처를 쓰되, 공개 전에는 식별 정보만 한 번 더 확인합니다.

현재 페이지에는 직접 선별한 원본 캡처를 사용했습니다. 공개 배포본에서는 주문번호, 환자명, 병원명, 내부 경로가 화면에 남지 않도록 한 번 더 확인하고, 필요한 부분은 민감정보 제거 버전으로 교체할 예정입니다.
