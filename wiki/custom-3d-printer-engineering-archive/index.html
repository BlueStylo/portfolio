P07 / 제작·프린팅

Mechanical rebuild evidence

CAD, 출력 부품, 장착 사진으로 프린터 개조 흐름을 보여줍니다.

CR-10 전장부 설계, Willybot CoreXY 리빌드, 노즐캠 마운트, Flsun Q5 덕트 모델링을 묶어 기구 설계와 실제 장착 검증이 이어진 기록으로 정리했습니다.

개요

  • 3D 프린터 개조 기록은 직접 기계를 분해하고 문제를 해결한 제조/하드웨어 역량을 보여주는 대표 제작 엔지니어링 축입니다.
  • Delta 보정, Klipper 전환, Input Shaping, Pressure Advance, direct extruder, CoreXY conversion, Voron head mod 같은 기록을 하드웨어 개조에서 출력 품질 개선까지 이어지는 흐름으로 묶습니다.
  • P05/P06/P08은 P07의 하위 챕터로 두고, P04는 펌웨어 설치와 보정 과정을 증명하는 세부 로그로 연결합니다. Bambu Lab 생산 운영 자료는 P09로 분리합니다.

역할

하드웨어 구조를 분해해 문제 원인을 찾고, toolhead/구동부 개조와 Klipper 기반 firmware calibration을 함께 적용해 출력 품질을 개선했습니다.

문제

  • 3D 프린터 품질 문제는 소프트웨어 설정, 펌웨어, 공진, 압출, 보우덴 구조, 헤드 무게, 프레임 구조, 소재가 모두 얽힙니다.
  • 단순히 장비를 쓰는 수준이 아니라 원인을 분해하고 기구와 펌웨어 양쪽에서 보정해야 했습니다.

내가 한 결정

  • 기구부를 먼저 확인한 뒤 Klipper 펌웨어 전환, 공진 보정, 압출 보정, 스큐 보정 순서로 문제를 좁히는 방향을 선택했습니다.
  • 필요할 경우 toolhead와 구동부를 다시 설계하고, 경량화와 강성을 위해 소재와 출력 조건까지 함께 조정했습니다.

과정

  • Delta printer tuning, FlyingBear Reborn + Voron head mod, Willybot CoreXY rebuild, bed wobble compensation을 P07 안의 하위 챕터로 정리합니다.
  • 개조 후에는 P04의 KIAUH/Klipper 설치, KlipperScreen/Crowsnest 구성, Input Shaping/Pressure Advance/Skew correction 로그를 근거로 연결합니다.
  • 현재 공개본에는 개조 사진이 부족한 구간은 SVG 도식으로 먼저 설명하고, 실제 사진과 보정 그래프가 확인되는 대로 같은 섹션에 교체·추가합니다.
  • 회사 생산 문서와 Bambu/AMS 운영 자료는 P09로 분리해, P07은 개인/기술적 개조 경험에 집중합니다.

검증

  • Input Shaping graph, Pressure Advance test print, before-after print quality, toolhead photo, wiring photo를 핵심 증거로 둡니다.
  • 보정 로그는 P04에 남기고, P07 본문에서는 문제 진단과 출력 품질 개선 흐름을 읽기 쉽게 요약합니다.

결과

  • 소프트웨어와 물리 시스템이 만나는 문제를 직접 해결한 대표 제작 경험입니다.
  • 의료 3D pipeline이 디지털 결과물을 만드는 것이라면, 이 항목은 그 결과를 실제 제조 환경으로 연결하는 배경이 됩니다.

증거

  • Klipper 설치와 Input Shaping, Pressure Advance, Skew correction 보정 기록
  • FlyingBear Reborn Voron head mod, Willybot CoreXY rebuild, bed wobble compensation 하위 기록
  • toolhead, Bowden/direct extruder, 구동부, 배선, 원격 제어 환경을 함께 다룬 튜닝 로그

보강할 근거 자료

  • 프린터 개조 사진
  • Input Shaping 결과 그래프
  • Pressure Advance 테스트 출력
  • 출력 품질 before/after

공개 기준

  • 학생 시절 장비 사진과 calibration graph는 다른 컴퓨터에서 추가 수집이 필요합니다.
  • 자료가 부족한 부분은 실제 경험을 과장하지 않고, 공개용 도식과 수집 예정 증거 목록으로 표시합니다.
