Motion tuning and teleoperation / 2026.07.23–07.26

미리 짜둔 타임라인을 재생하는 단계에서, 손으로 직접 끌고 다니는 제어까지 넓혔습니다.

동작이 덜컹거릴 때 감으로 값을 바꾸지 않고, 프로파일과 jerk, 가속, 블렌딩 반경을 한 번에 하나씩만 바꿔 실기에서 비교했습니다. 그다음에는 미리 정해둔 경로를 재생하는 대신 사람이 만든 궤적을 그대로 따라오게 만드는 쪽으로 넘어갔습니다.

01Profile A/B

TOPPRA·Ruckig, jerk 100 대 20, 가속 50 대 25를 단일 변수로 비교

02Queued MoveJ blend

6개 MoveJ를 미리 queue해 host 간격 제거, 반경 0 대 1mm 비교

03ServoJ live follow

단일 세션·Web Worker 전송·연속성 시드 IK·지연 측정, 반응 약 3.5배

04WebXR teleoperation

Quest 3의 6DoF 포즈를 로봇 좌표계로 변환, bounded target으로 범위 제한

웹 제어 인터페이스는 오픈소스 Pilot에서 출발했고, 핵심 제어 경로는 사실상 다시 썼습니다. 블렌딩 A/B 러너는 실행 중 command index 소유권을 감시해서, 요청한 jerk·반경·속도와 실제 실행값이 다르면 그 자리에서 HALT하도록 만들었습니다. Pilot에는 이틀 동안 72개 파일에 19,530줄을 더하고 4,798줄을 걷어내며 신규 파일 40개를 추가해 전체 코드가 34,842줄에서 49,065줄이 됐습니다. commander 제어 루프와 robot_client, kinematics 같은 핵심 경로는 사실상 다시 썼고, IK 런타임과 서보 전송, 좌표 정렬은 브라우저 런타임 검증 스크립트와 계약 테스트로 회귀 확인했습니다.
