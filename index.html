AI·의료 3D

의료 3D AI 파이프라인

2D TransUNet, 3D TransUNet, U-Mamba, Swin-Unet까지 직접 테스트하고 단일 GPU 40GB 이상 VRAM이 필요한 3D 후보 실험을 위해 RTX PRO 6000 96GB 기반 Linux 학습 서버를 구성한 뒤, nnU-Net v2를 파인튜닝해 DICOM 입력, mask 후처리, STL 생성, 웹 미리보기까지 이어 붙인 의료 3D AI 파이프라인.

문제 최신 CT 분할 모델은 많습니다. 하지만 매일 돌리는 환경에서는 정확도만으로는 부족했습니다. 단일 GPU VRAM, 추론 시간, 추가학습, 유지보수, 결과 검토 흐름이 전부 맞아떨어져야 했습니다.

역할 2D·3D TransUNet과 U-Mamba를 직접 돌려보고, 40GB 넘는 VRAM이 필요한 3D 후보를 시험하려 RTX PRO 6000 96GB Linux 학습 서버까지 세웠습니다. 그러고 나서 nnU-Net v2를 운영 모델로 골랐습니다.

증거 운영 대시보드(2026.07) 기준 누적 746회 실행, 기술적 완료율 98.5%, 40~90분 걸리던 수작업을 평균 7.5분으로 줄인 기록이 있습니다. 모델 후보 trade-off, 학습 서버 구성, 검토 패키지, 진행 로그, mesh preview, 익명화한 파이프라인 다이어그램으로 남겨 두었습니다.

산업 AI·검증

MoldTrace 멀티모달 검증 코파일럿

제조 컨펌 스레드에서 수집 계정 멘션이 감지되면 n8n이 전체 대화와 몰드 이미지·PDF를 읽기 전용으로 수집·별칭화하고, 규칙 엔진 5종의 결정론 검사를 거쳐 self-hosted Gemma 4(31B)가 단 한 번의 멀티모달 호출로 수주·라벨·몰드 각인을 대조해 격리된 검토 채널에 검증 리포트를 남기는 human-in-the-loop 검증 코파일럿입니다. 합성 채널 라이브 데모의 MISMATCH 검출과 실제 운영 수주 스레드 30건의 Shadow Review 전체 왕복을 거쳐, 2026.07부터 담당자가 실제 업무에서 쓰고 있습니다.

문제 제조 컨펌은 사람이 스레드와 몰드 이미지를 눈으로 대조하는 반복 작업입니다. 비정형 수정 대화 때문에 규칙 기반 파서는 깨졌고, 통제 없는 모델은 잘못된 출력을 그대로 게시할 수 있었습니다.

역할 n8n 읽기 전용 Shadow 수집·별칭화, Python fail-closed 계약과 PDF 전 페이지 변환, 규칙 엔진 5종의 결정론 검사, self-hosted Gemma 4의 one-shot 멀티모달 판단으로 책임을 분리한 검증 코파일럿을 단독 구축했습니다. 결정론 baseline에서 출발해 중간 2단계 구조의 문맥 손실을 겪은 뒤 one-shot 호출로 단순화했고, 실데이터 Shadow Review까지 구조를 직접 진화시켰습니다.

증거 합성 채널 라이브 데모에서 주문번호 불일치를 MISMATCH 리포트로 검출·게시했고, 실제 운영 수주 스레드 30건의 Shadow Review 전체 왕복까지 확인했습니다. 69개 계약·안전 테스트와 합성 390건 결정론 baseline 평가를 함께 남겼고, 2026.07부터 담당자가 실제 업무에서 쓰고 있습니다.

설계 자동화

맞춤형 보형물 설계 자동화 도구

Rhino/Grasshopper 기반 코 임플란트 설계 자동화 엔진을 v0.00.0에서 v5.00.0까지 138개 버전을 거치며 고도화하고, 매개변수 입력부터 최종 3D 프린팅용 STL 파트 추출까지 마법사형 UI로 일원화한 제조 자동화 프로젝트입니다.

문제 맞춤형 보형물 설계는 반복이 많고, 설계자마다 판단이 갈립니다. 속도도 일관성도 같이 흔들렸습니다.

역할 Rhino/Grasshopper 로직을 데이터 입력부터 STL 파트 제작까지 이어지는 7단계 순서형 UI와 저장·불러오기 흐름으로 감쌌습니다.

증거 138개 버전, 15,337개 오브젝트, 7단계 작업자 UI — 노드 기반 자동화를 실제 설계자가 쓰는 도구로 바꾼 기록입니다.

AI·의료 3D

이미지 기반 얼굴 3D 복원·정합

HRN 모델의 기본 텍스처 해상도(256px) 한계를 2048px 고해상도로 극복하고, MediaPipe 랜드마크 추출, Rigid ICP, Eye Mask 기반 Non-rigid Registration을 연계하여 이미지 복원 메쉬를 실제 CT 데이터와 정교하게 정합하는 파이프라인을 구축했습니다.

문제 스마트폰 사진으로 만든 얼굴 mesh와 CT에서 뽑은 mesh는 좌표계도, 해상도도, 텍스처 조건도 다릅니다. 그대로는 가상성형 흐름에 바로 올릴 수 없었습니다.

역할 HRN과 MediaPipe landmark, 강체·비강체 정합을 엮어 사진으로 만든 얼굴과 CT mesh를 같은 기준에서 맞추는 흐름을 직접 짰습니다.

증거 동의받은 case01에서 256px HRN 텍스처를 2048px로 끌어올리고, CT overlay와 정합 애니메이션으로 직접 확인했습니다. 이 복원·정합 주제의 공동 연구 논문이 CMES 저널에 투고되어 심사 중입니다(제2저자).

로보틱스·임베디드

PAROL6 로봇팔 · Octopus Pro Bring-up

오픈소스 PAROL6의 기계부를 직접 출력·조립하고 BTT Octopus Pro V1.0 F446에 원본 프로토콜과 호밍 로직을 최대한 보존해 이식한 뒤, 6축 실기기 HOME, Meta Quest 3 원격조작, Unity 혼합현실 디지털 트윈을 거쳐 VR로 만든 목표 자세를 keyframe으로 기록하고 반복 실행하는 단계까지 연결한 진행형 로보틱스 프로젝트.

문제 오픈소스 로봇팔의 제어보드를 바꾸려면 clock, USB, 핀맵뿐 아니라 24V 센서 절연, 드라이버 배치, 축 방향과 호밍 순서까지 실제 기구에 맞춰 다시 검증해야 합니다.

역할 PAROL6를 출력·조립하고 Octopus Pro F446 최소 포팅, TMC5160 6축 배선, 센서 인터페이스, STOP7 정지 로직과 진단 웹 UI를 연결한 뒤 Quest 3 원격조작, Unity 혼합현실 디지털 트윈, VR 목표 자세의 keyframe 기록·반복 실행까지 확장했습니다.

증거 6축 구동과 엔드센서 입력, 전체축 HOME, 실기기 dance motion을 확인했습니다. 이후 Quest 3 원격조작, 실제 로봇팔과 디지털 트윈의 자세 비교, VR 목표 입력→keyframe 저장→실기 반복 실행을 영상으로 남겼습니다.
