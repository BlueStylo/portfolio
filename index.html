사진에서 복원한 얼굴 메쉬를 CT 메쉬 기준으로 정렬하는 파이프라인입니다. HRN 복원 결과에 원본 사진을 다시 입혀 텍스처를 살리고, 랜드마크 정렬과 강체 정합, 눈 영역 마스크를 적용한 비강체 정합으로 이어집니다.

직접 맡은 범위

복원 모델 선정, 멀티뷰 텍스처 블렌딩, MediaPipe 랜드마크 정렬, Rigid ICP, 마스크 가중 비강체 정합

2048px

멀티뷰 블렌딩 텍스처

왜 이렇게 만들었나왜 CT를 고정하고 얼굴 메쉬만 움직였나요?+
제약
CT 메쉬는 이후 설계 단계가 기준으로 삼는 좌표계라 움직일 수 없었습니다. 사진에서 복원한 메쉬는 스케일과 자세가 매번 달랐고, 눈을 뜬 사진과 눈을 감은 CT의 차이도 있었습니다.
선택
CT를 기준으로 두고 HRN 메쉬의 스케일, 위치, 회전을 먼저 맞춘 뒤 강체 정합과 비강체 정합을 나눠 처리했습니다. 눈 영역은 마스크 가중치를 낮춰 정합이 끌려가지 않게 했습니다.
결과
사진으로 복원한 얼굴 메쉬를 CT 좌표계에 올리는 전 과정을 하나의 파이프라인으로 연결하고, 텍스처를 256px에서 2048px로 끌어올렸습니다. 같은 복원과 정합 주제로 광운대학교와 진행한 산학 공동 연구에 제2저자로 참여했고, 논문은 CMES 심사 중입니다.

드론 촬영 / 가우시안 스플래팅 3D

개인 프로젝트 / 2026.09 주민 공개

드론으로 찍은 동네를,
돌려 볼 수 있는 3D로.

가족 별장이 있는 경기 양평 양동면의 집과 동네를 DJI Mini 3로 4K 30fps 촬영하고, 영상에서 1초에 한 장씩 뽑은 682장을 COLMAP으로 한 좌표계에 정합했습니다. 이 프레임으로 Mac M1 Pro에서 Brush 가우시안 스플래팅을 12,000단계 학습하고, 결과를 웹 뷰어로 만들어 동네 주민에게 링크로 공개했습니다. CT에서 3D를 뽑아 설계 도구에 넣는 본업과 같은 구조를, 대상만 건물과 대지로 바꿔 촬영부터 배포까지 혼자 이어 본 프로젝트입니다.

직접 맡은 범위

드론 촬영, 프레임 추출, COLMAP 정합, Brush 학습, PLY 압축, PlayCanvas 뷰어 제작, 라즈베리파이 배포

왜 이렇게 만들었나왜 집을 먼저 복원하고 동네를 나중에 더했나요?+
제약
집 촬영분만으로는 동네 배치가 담기지 않고, 동네 촬영분을 나중에 더하면 두 촬영분이 하나의 좌표계로 맞아야 합니다. 떨어진 촬영 구간을 잇는 정합이 필요했습니다.
선택
집 389장으로 먼저 복원해 기준을 만든 뒤, 동네 293장을 더한 682장을 기존 집의 카메라 정보를 기준으로 COLMAP에서 하나의 좌표계에 정렬했습니다. 기존 PLY를 이어 붙이지 않고 통합 정합 결과로 Brush에서 12,000단계 새로 학습했습니다.
결과
